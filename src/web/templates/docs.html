tasktracker api
Visão geral Tarefas API

TaskTracker API

API REST que usa o mesmo núcleo de regras do terminal. Os dados ficam no mesmo SQLite que o terminal grava, então uma tarefa cadastrada em um lugar aparece no outro.

Servidor: http://localhost:8000

Tarefas

GET/tarefas

Lista as tarefas ordenadas pela data limite. Filtros opcionais: ?prioridade=Alta e ?status=Pendente.

Resposta 200

[
  {
    "id": 1,
    "titulo": "Escrever testes do repositório",
    "descricao": "Cobrir adicionar, listar e concluir",
    "prioridade": "Alta",
    "data_limite": "2026-10-20",
    "status": "Pendente",
    "data_limite_br": "20/10/2026",
    "prazo": "vence em 2 dias",
    "atrasada": false
  }
]
POST/tarefas

Cadastra uma tarefa com as mesmas validações do terminal. A tarefa começa como Pendente.

Corpo da requisição (JSON)

{
  "titulo": "Escrever testes do repositório",
  "descricao": "Cobrir adicionar, listar e concluir",
  "prioridade": "alta",
  "data_limite": "20/10/2026"
}

Resposta 201: tarefa criada

{ "id": 9, "titulo": "Escrever testes do repositório", "prioridade": "Alta", "data_limite": "2026-10-20", "status": "Pendente", ... }

Resposta 422: campo inválido, com a mesma mensagem do terminal

{ "erro": { "campo": "data_limite", "mensagem": "Erro: data inválida. Use DD/MM/AAAA com uma data real." } }
PATCH/tarefas/{id}/concluir

Marca a tarefa como Concluída. Responde 404 se o id não existir.

Painel

GET/estatisticas

Totais por prioridade, situação e prazo, usados na visão geral.

{ "total": 8, "pendentes": 6, "concluidas": 2, "percentual_concluidas": 25, "atrasadas": 1, "vencem_em_7_dias": 3,
  "por_prioridade": { "Alta": { "total": 3, "pendentes": 3, "concluidas": 0 }, ... },
  "hoje": "18/10/2026", "proximos_prazos": [ ... ] }
